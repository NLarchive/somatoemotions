# Project specification: SomatoEmotions

Generated by npm run spec from repository-local tooling.

## Current architecture

Static ES-module browser atlas, package 4.0.0, atlas schema 4.0.0. Root entry: index.html -> app.js -> src/workflows/atlas-runtime/main.js. Domain -> ports -> injected fetch adapter/services -> UI -> workflows. No backend/API or accounts. Registry: src/registry.json. Plan: node.tasks.json.

## Data and images

14 emotion labels. face: 54 WebP / 54 JPEG; action: 42 WebP / 42 JPEG; somatic: 130 WebP / 130 JPEG. Images are AI-generated illustrations. Sources and publication decisions live in sources.json and docs/evidence-review.json. Original unsupported claims/metrics are archived in docs/legacy-data.json. Source JPEGs use images/jpg/{type}/{name}.jpg; runtime WebPs use images/{type}/{name}.webp.
